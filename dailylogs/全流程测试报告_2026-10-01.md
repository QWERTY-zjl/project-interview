## 四、新发现问题

### 4.1 【新回归】5 个「单字段 Body 参数」接口与前端契约不兼容 → 422

**这是 2026-09-30 API 装饰器化重构引入的回归，修复前用户核心路径会挂。**

**根因**：FastAPI 中单个标量 `Body(...)` 参数默认要求请求体是**裸 JSON 值**（如 `"friendly_female"`），而前端全部发送 JSON **对象**（如 `{"voice_type": "friendly_female"}`）→ 422。用「裸值形态」对同一接口复测可正常进入业务逻辑，证实根因是函数签名而非业务代码。

```python
# 现在（有问题）：
async def set_interview_voice(token: str = Path(...), voice_type: str = Body(...)):
# 修复方向：加 embed=True，告诉 FastAPI 参数嵌在 JSON 对象里
async def set_interview_voice(token: str = Path(...), voice_type: str = Body(..., embed=True)):
```

| 接口 | 前端调用点 | 影响 |
|---|---|---|
| POST `/api/evaluation/generate` | `app/static/interview.html:2788` | **面试收尾生成报告，用户路径必现 422，影响面最大** |
| POST `/api/interview/{token}/set_voice` | `app/static/interview.html:1895` | 设置音色失败 |
| POST `/api/interview/{token}/toggle_voice_reading` | `app/static/interview.html:1874` | 切换朗读失败 |
| POST `/api/orders/pay` | `app/static/pricing.html:516` | 支付失败（目前被 payment_module 503 掩盖） |
| POST `/api/payment/mock/confirm` | `app/static/pricing.html:547` | mock 支付失败（同上） |

修复极小：5 处各加 `embed=True`。**截至本报告撰写，尚未修复（用户决定先不修）。**

### 4.2 【行为差异】简历上传链路未走 MinerU

现役 `app/api/resume_api.py` 对原始文件字节直接做本地正则 `analyze_resume`（PDF 二进制按 utf-8/gbk 容错解码），MinerU 只存在于遗留 `server.py`（约 1689 行，已定位为只读参考代码）。

实测上传 885B PDF 耗时 **0.007~0.03s**（无 GPU 解析环节）；链条上也没有「自动调 LLM 分析简历」的调用点，出题走默认问题降级。

**代价**：真实 PDF 的文本提取质量显著低于 MinerU 路径。属于架构取舍而非 bug，是否恢复 MinerU 链路需单独决策。
