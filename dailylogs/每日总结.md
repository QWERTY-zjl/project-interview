### 1. mineru 部署：重建虚拟环境（已完成）
- 原 venv 是 Python 3.14.3，而 mineru 所有版本都要求 >=3.10,<3.14，无法安装
- mineru 下载模型会自动调用 huggingface，配好镜像 HF_ENDPOINT=https://hf-mirror.com（用户级环境变量），但发现依赖下载还是很慢
- 和ai商讨后，将安装方式改成 uv（并行下载，快很多）；过程中发现系统 Python 3.13 是非标准安装——标准库 /Lib 跑到 D 盘去了，导致 uv 找不到 python 解释器，于是用 uv 下了新的 Python 3.13.15（uv 托管，与系统 Python 共存）
- 用 uv 后 90 秒装完了 pip 一个多小时没装完的 mineru[core]==2.7.6 + 全部项目依赖（openai 固定 2.30.0）
- torch 换装 2.11.0+cu128（走上海交大镜像，1.9GB 约 5 分钟）；踩坑：先装了 cu130 报 cudaErrorNotSupported，因为驱动 566.24 最高只支持 CUDA 12.7
- 实测通过：torch.cuda.is_available() == True（RTX 4060），mineru --version == 2.7.6
- 下一步：预下载模型权重（步骤 3），然后开始代码重构（ai-services → ai_services）
