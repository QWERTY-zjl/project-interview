==========================================
 AI 面试模拟系统 - 安装运行说明
==========================================

【环境要求】
- 操作系统：Windows 10 / 11（64 位）
- Python：3.10 或以上版本（下载地址 https://www.python.org/downloads/）
  安装时务必勾选 "Add Python to PATH"
- 浏览器：Chrome / Edge（推荐 Chrome，语音识别功能更完整）
- 网络：需要联网调用 AI 模型服务

【安装步骤（共 4 步）】

第 1 步：双击 setup.bat
  自动创建虚拟环境并安装依赖，首次安装约需 3~5 分钟。

第 2 步：配置 API Key
  作品包内已附带配置好的 .env 文件（内置作品方提供的体验密钥），
  本步骤可跳过，直接进入第 3 步。
  若提示额度耗尽或密钥失效，按以下方式替换为自己的：
  用记事本打开 .env，找到 DASHSCOPE_API_KEY 一行，填入你的
  阿里云百炼 API Key。获取方式：访问阿里云百炼控制台
  （https://bailian.console.aliyun.com），开通模型服务后在
  "API-KEY 管理" 页面创建即可，新账号有免费额度。

第 3 步：启动系统
  双击 start_personal_server.bat，看到
  "Uvicorn running on http://0.0.0.0:10009"
  即启动成功（启动窗口请保持打开，关闭窗口即退出系统）。

第 4 步：开始使用
  浏览器打开 http://127.0.0.1:10009
  注册账号登录 -> 工作台选择面试官音色 -> 上传简历并填写目标岗位
  -> 等待约 2 分钟 AI 出题 -> 开始语音/文字面试 -> 查看面试报告

【常见问题】

1. 提示 "未检测到 Python"
   未安装 Python 或未勾选 Add to PATH，重装时勾选即可。

2. 双击启动后浏览器打不开页面
   检查启动窗口是否报错；确认访问地址是 http://127.0.0.1:10009
   （不要用 https）。

3. 上传简历后出题失败
   检查 .env 中 DASHSCOPE_API_KEY 是否填写正确、账号额度是否充足；
   确认简历是文字版（扫描图片型 PDF 无法提取文字）。

4. 端口被占用
   关闭占用 10009 端口的其他程序后重新启动。

【首次使用建议】
注册账号后系统赠送 3 次面试次数；第一次面试建议先选择音色并试听，
上传完整真实的简历效果最佳（AI 会围绕你的项目经历出题）。
